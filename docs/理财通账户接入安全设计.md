# 理财通账户数据接入：安全与兼容性设计

## 当前状态

- 未确认腾讯理财通向个人开发者提供可用的官方 API；此目录不实现登录、网页抓取或非公开接口。
- 首期支持由用户从官方渠道导出的 CSV/JSON 交易流水和持仓快照。
- `tools/account_import.py` 只做本地文件导入、字段标准化、重复检测和导入清单记录；不会联网，不会伪造缺失字段。
- 默认输出目录为 `private_account/`，已列入 .gitignore。文件权限尽量限制为目录 0700、数据文件 0600（在支持 POSIX 权限的系统上）。
- 导入后的记录保留 `source_row` 原始行，缺少的数据留空。自动字段映射仅覆盖常见中文列名，导入前必须核对报告。

## 重要：当前公开仓库仍需迁移

该项目历史结构把 `portfolio.json` 和 `data/dashboard_history.json` 放在公开仓库中；当前网站同步脚本还会将账户汇总和持仓写入 `site/data/latest.json` / `site/data/history.json`。仅添加 .gitignore 不会停止跟踪已经提交的文件，也不会清除 Git 历史。

**在完成私有存储迁移之前，不要将真实理财通导出文件放入仓库，也不要将本分支视为已完成隐私修复。** 需要后续迁移：
1. 建立独立的私有账户数据仓库或受访问控制的私有存储。
2. 将 `portfolio.json`、账户交易流水和持仓历史迁出公开仓库。
3. 修改每日更新流程，从私有存储读取账户数据，并只向公开 Pages 发布经过明确白名单筛选的市场估值数据。
4. 从公开页面移除账户余额、成本、盈亏、基金份额及交易流水。
5. 检查并按需要清理公开 Git 历史；当前文件删除不等于旧提交已消失。
6. 运行公开产物扫描，确认 `site/data` 不含账户字段。

## 导入命令

```bash
python tools/account_import.py --transactions /path/to/transactions.csv --snapshot /path/to/holdings.csv
```

可以单独导入其中一种。重复导入会根据交易 ID（若存在）或一组字段生成去重键；无唯一交易 ID 时，去重只是启发式，可能需要人工对账。

## 数据模型

交易记录标准字段：交易日期、交易单号、类型、基金代码/名称、金额、份额、确认净值、手续费、状态、原始行、来源文件、导入时间。

持仓快照标准字段：快照时间、基金代码/名称、份额、市值、成本、现金余额、原始行、来源文件、导入时间。

## 官方接口启用条件

只有在理财通官方渠道明确确认接口、授权流程、可读字段、历史范围和使用条款后，才另行实现适配器。适配器必须支持授权撤销、最小权限、分页、限流、幂等同步和来源/时间记录。不得存储账户密码、支付密码或短信验证码。
